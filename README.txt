Root Manager by Jhon Simbulas

Android 15/API 35 root policy manager.
UI: dark cards, search, ALL/USER/SYSTEM/ROOT tabs, app icons, UID, policy and ON/OFF switches.
Uses a ListView adapter for stable rendering of large app lists.

Build in Termux:
  cd ~/RootManager
  # replace src/main/AndroidManifest.xml and src/main/java/com/local/rootmanager/MainActivity.java
  # then use build-termux.sh below
